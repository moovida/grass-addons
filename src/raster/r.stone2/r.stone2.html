DESCRIPTION

r.stone2 tries to model tri-dimensional paths of stones falling down a DTM. Input DTM is a square fixed spaced DTM, but it is used as a Triangular Regular Network. Triangles are built on the fly during run-time. Paths are evaluated using parametric 2nd order equations after a roto-translation of the coordinate system to the run-time triangle.
